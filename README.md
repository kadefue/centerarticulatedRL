Autonomous Field Rover: Physics-Based Control SimulationThis project simulates the dynamics and control of an articulated electrical field rover. It provides a comparative analysis of geometric, hybrid, and reinforcement learning control strategies across varying terrain conditions, focusing on the trade-off between path tracking accuracy and energy efficiency.📋 OverviewThe simulation models a kinematic vehicle subject to terrain-specific physics (slip ratios and rolling resistance). It acts as a testbed to evaluate:Pure Pursuit: Classic geometric path tracking.Fue MPP (Modified Pure Pursuit): Hybrid control using geometric lookahead + Cross-Track Error (CTE) feedback.RL Agent (Q-Learning): An adaptive agent that optimizes speed and steering gain based on environmental states.🛠 DependenciesThe simulation relies on standard scientific Python libraries.pip install numpy matplotlib scipy
🏗 System Architecture1. Vehicle Physics (ElectricalVehicle)The rover is modeled as a kinematic system with integrated power estimation:Actuator Dynamics: Steering ($\gamma$) and acceleration ($v$) are rate-limited.Slip Physics: Effective velocity is derived as $v_{eff} = v \cdot (1 - slip)$.Energy Model: Calculates energy (kJ) based on:Rolling Resistance: $F_{roll} = mg \cdot C_{rr}$Acceleration Force: $F_{accel} = ma$Steering Load: Power required to articulate wheels against ground resistance.2. Terrain ModelsThree terrain types are simulated, each affecting traction and energy consumption:Tarmac: Low Slip (0.02), Low Drag.Rough: Moderate Slip (0.1), Medium Drag.Mud: High Slip (0.2), High Drag. Note: High slip wastes significant energy and reduces steering authority.🧠 Control AlgorithmsA. Pure Pursuit (Baseline)A standard geometric controller that steers towards a lookahead point on the path.Pros: Stable, easy to implement.Cons: Prone to "cutting corners" (steady-state error) on sharp turns.B. Fue MPP (Hybrid)A modified controller designed to reduce tracking error.Logic: $\gamma_{cmd} = \gamma_{geo} - (K_p \cdot CTE)$Mechanism: Injects a proportional term based on Cross-Track Error (CTE) into the geometric command to force tighter path convergence.C. Q-Learning Agent (RL)An adaptive discrete controller.State Space: [CTE Bin, Heading Error Bin, Future Curvature, Slip]Action Space: 5 pairs of (Steering Gain, Target Speed).Behavior: Learns to slow down and increase steering gain in mud or sharp corners, and cruise on straights.🚀 UsageRun the simulation directly:python rover_simulation.py
Execution FlowTraining: The RL agent trains for 1500-3500 episodes. A plot will show reward convergence.Action: Close the training plot window to proceed.Comparison: The script runs all three controllers on a "Square" path (high difficulty).Visualization: Generates a 3x3 grid showing trajectory, velocity, and steering profiles.📊 Output MetricsThe console outputs a table comparing performance:MetricDescriptionRMSE (m)Root Mean Square Error of path tracking.MAX ERR (m)Maximum deviation from the center line.ENERGY (kJ)Total energy consumed (Propulsion + Steering).Sample Output==========================================================================================
